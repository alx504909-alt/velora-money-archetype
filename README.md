# Денежный архетип — MVP v0.4

Статический MVP воронки Velora для проверки спроса на PDF-разбор за 199 ₽.

## Что внутри
- Premium/editorial лендинг.
- Hero-визуал.
- Бесплатный тест на 10 вопросов.
- 6 денежных архетипов.
- Бесплатный результат до предложения оплаты.
- Блок “Где деньги” в результате.
- Оффер PDF за 199 ₽.
- Модалка раннего интереса к покупке.
- Локальная фиксация событий в `localStorage`.
- OG/meta/favicons для публикации.

## Локальный запуск
```bash
cd /root/velora-money-archetype
python3 -m http.server 8080
```
Открыть: http://localhost:8080

## MVP-события
Пока без внешней аналитики события сохраняются в браузере:
- `velora_mvp_events` — `quiz_start`, `quiz_finish`, `pdf_interest`;
- `velora_pdf_interest` — клики по покупке PDF с результатом, временем, ценой и `utm_source`.

Проверить в DevTools → Application → Local Storage.

## Публикация
Подходит для GitHub Pages / Netlify / Vercel как обычный статический сайт.

Главные файлы для загрузки:
- `index.html`
- `styles.css`
- `app.js`
- папка `assets/`
- `.nojekyll`

## Следующий этап после публикации
1. Прогнать 20–50 первых посетителей.
2. Смотреть не лайки, а прохождения теста и клики по PDF.
3. Если клики по PDF есть — подключить оплату.
4. Сделать автоматическую выдачу PDF.

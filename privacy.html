Конфиденциальность

Политика конфиденциальности

Сайт Velora собирает минимальный объём данных, необходимый для работы теста и оплаты цифрового продукта.

Какие данные могут обрабатываться

  • Ответы в тесте — используются для показа результата в браузере.
  • Технические данные браузера — для корректной работы сайта.
  • Платёжные данные — обрабатываются платёжным сервисом, сайт не хранит данные банковских карт.

Цель обработки

Показ результата теста, проведение оплаты, выдача цифрового PDF-продукта и обработка обращений покупателя.

Передача данных

Платёжные данные передаются платёжному провайдеру для проведения оплаты. Данные банковских карт не попадают на сайт Velora.
